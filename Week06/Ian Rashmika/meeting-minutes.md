## 1. Meeting Purpose

The purpose of the Week 6 meeting was to review the project's innovation strategy and connect the strategic objectives to technical implementation.

The team also reviewed current technical progress, responsibilities, integration requirements, and upcoming development activities.

## 2. Innovation Classification

The team reviewed the project against the following innovation types:

- Incremental
- Disruptive
- Radical
- Architectural

Architectural innovation was identified as the most appropriate classification because the project combines existing AI security technologies and techniques into a modular, controlled, and offline testing architecture.

## 3. Technical Direction

The team discussed the proposed technical workflow:

Test Configuration / Dataset  
→ Attack Testing  
→ Target AI Model / Agent  
→ Defence / Resilience Controls  
→ Response Collection  
→ Evaluation  
→ Security Findings

The architecture is intended to support controlled and reproducible AI security testing.

## 4. Current Technical Progress

The team reviewed the current state of the model-layer experimentation and associated testing environment.

The model-layer work provides an initial basis for evaluating differences in model behaviour under controlled security testing.

The team agreed that planned components must be clearly distinguished from components that are currently working.

## 5. Team Responsibilities

## 6. Key Decisions

- Treat the project primarily as architectural innovation.
- Continue using a modular approach to technical development.
- Keep testing within an authorised and controlled environment.
- Use measurable evaluation criteria when comparing security behaviour.
- Maintain accessible GitHub evidence for completed project work.
- Clearly identify whether technical components are working, in progress, or planned.

## 7. Current Challenges

The main integration challenge is ensuring that independently developed attack, defence, and evaluation components can eventually operate through a consistent workflow.

Common input/output formats and clear interfaces will be important for later integration.

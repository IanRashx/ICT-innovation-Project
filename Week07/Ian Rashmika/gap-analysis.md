# Week 7 – Project Gap Analysis

**Member:** Ian Rashmika  
**Role:** Project Lead / Coordination

## 1. Purpose

The purpose of this gap analysis is to compare the current state of the Agent Resilience project with the desired end state and identify actions required to close the remaining gaps.

## 2. Current Project Objectives and Gaps

### Objective 1 – Reproducible Local Testing Environment

**Current state:**  
A local Qwen model-layer testing environment has been established and used for controlled experimentation.

**Gap:**  
Setup and execution need to be consistently reproducible across team members.

**Action:**  
Improve setup documentation, dependency information and execution instructions and validate the workflow with another team member.

### Objective 2 – Controlled Adversarial Testing

**Current state:**  
Model-layer experimentation and baseline-versus-modified model testing have been performed.

**Gap:**  
Testing requires consistent datasets, execution procedures and result recording.

**Action:**  
Standardise test inputs and output formats and repeat agreed test cases using the common procedure.

### Objective 3 – Defence and Resilience

**Current state:**  
Relevant defence approaches have been identified.

**Gap:**  
Defence components are not yet fully integrated into the common testing workflow.

**Action:**  
Progress implementation and testing of agreed resilience controls using both adversarial and benign inputs.

### Objective 4 – Security Evaluation

**Current state:**  
Evaluation measures including Attack Success Rate, jailbreak detection rate, benign prompt acceptance, refusal behaviour and system reliability have been identified.

**Gap:**  
Metrics need to be consistently calculated from actual test outputs.

**Action:**  
Establish a common result structure and apply the agreed evaluation metrics.

### Objective 5 – Toolkit Integration

**Current state:**  
The proposed architecture and integration approach have been defined.

**Gap:**  
Full end-to-end integration remains incomplete.

**Action:**  
Agree on interfaces and incrementally connect attack, defence, response collection and evaluation components.

## 3. Priority Gaps

The highest-priority gaps are:

1. End-to-end technical integration.
2. Defence/resilience implementation and testing.
3. Consistent evaluation of technical results.
4. Reproducibility across team environments.

## 4. Week 7 Direction

The team will prioritise closing integration and evaluation gaps while maintaining clear evidence of completed technical work.

Project progress will continue to be reviewed against the planned objectives and available project resources.

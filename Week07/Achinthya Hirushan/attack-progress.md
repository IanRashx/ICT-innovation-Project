# Week 7 – Attack Testing Progress

**Member:** Achinthya Hirushan  
**Role:** Red Team / Jailbreak Testing

## Current State

The attack-testing component focuses on controlled adversarial testing of the target AI system.

Model-layer experimentation provides an initial basis for examining how model behaviour changes under security testing.

## Progress

Current attack-testing work includes:

- controlled model-layer testing;
- use of adversarial/jailbreak test inputs;
- observation of model responses;
- comparison of baseline and modified behaviour; and
- recording of relevant testing evidence.

## Identified Gaps

The main gaps are:

- consistent test datasets;
- standardised execution procedures;
- common result formats; and
- integration with the evaluation component.

## Actions

The next actions are to:

1. finalise the agreed test cases;
2. execute tests consistently;
3. record outputs using the agreed result structure;
4. provide results to the evaluation component; and
5. maintain reproducible evidence in the repository.

## Week 7 Outcome

Week 7 identifies the remaining work required to move attack testing from individual experimentation toward a repeatable component of the wider Agent Resilience workflow.

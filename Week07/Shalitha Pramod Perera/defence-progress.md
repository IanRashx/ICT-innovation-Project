# Week 7 – Defence and Resilience Progress

**Member:** Shalitha Pramod Perera  
**Role:** Blue Team / Defence

## Current State

The defence component focuses on identifying and reducing potentially adversarial behaviour while maintaining legitimate system use.

Relevant resilience areas include:

- prompt filtering;
- jailbreak detection;
- tool/action restrictions; and
- monitoring and detection.

## Current Gap

The main gap is moving from identified defence approaches toward implementation and integration with the common security-testing workflow.

Controls that have not yet been technically implemented remain proposed controls.

## Actions

The next development steps are to:

1. select the agreed resilience control for implementation/testing;
2. test the control using adversarial inputs;
3. test legitimate prompts to identify unnecessary blocking;
4. record detection and response outcomes; and
5. provide results for evaluation.

## Evaluation

Defence effectiveness will be considered using measures such as:

- Attack Success Rate;
- jailbreak detection rate;
- benign prompt acceptance;
- refusal behaviour; and
- system reliability.

## Week 7 Outcome

The Week 7 review identifies the technical and integration work required to progress the defence component and connect it with attack testing and evaluation.

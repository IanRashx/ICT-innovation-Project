## Week 8 Focus

Week 8 focuses on developing a practical Testing and Quality Assurance
(QA) plan for the Agent Resilience project.

The team reviewed the features being developed and defined measurable
quality expectations for security, reliability, performance and
functional behaviour.

The team also defined preventive QA activities, detective QC activities,
testing responsibilities and the testing process that will be used during
the remaining development period.

---

## Main Quality Targets

The current project requirements include the following measurable targets:

- Jailbreak detection rate: at least 80%
- Benign prompt acceptance rate: at least 90%
- Detection processing time: no more than 2 seconds, excluding external
  model/API response time
- Planned evaluation test completion without application failure:
  at least 95%

These targets will be used as measurable criteria during technical testing.

## Testing Principle

Testing is restricted to authorised local or controlled project
environments.

Proposed components that have not yet been implemented are not reported as
successfully tested. Testing evidence will be added when the relevant
component is available for execution.

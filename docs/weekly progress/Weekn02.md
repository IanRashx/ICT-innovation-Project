# Current Project Problem

AI agents and Large Language Models may be vulnerable to adversarial inputs such
as jailbreak prompts.

These attacks may attempt to change the intended behaviour of the AI agent or
cause it to bypass expected restrictions.

The project will investigate how AI agent resilience can be evaluated and
potentially improved.

---

# Preliminary Proposed Solution Direction

The current proposed direction is a controlled AI testing environment.

A possible process is:

User/Test Prompt

↓

Prompt Analysis

↓

Jailbreak Detection

↓

Resilience / Protection Mechanism

↓

AI Agent

↓

Output Analysis

↓

Result Logging

↓

Resilience Evaluation

This is a preliminary design only and has not yet been confirmed with the
tutor/client.

# Week 2 Functional Requirements

- FR1 – Submit normal and adversarial test prompts.
- FR2 – Detect potentially suspicious or jailbreak-style prompts.
- FR3 – Apply a resilience mechanism.
- FR4 – Record and display testing results.

---

# Week 2 Non-Functional Requirements

Preliminary targets:

- Detection processing time: approximately 2 seconds or less, excluding external
  AI response time.
- Jailbreak detection target: at least 80% on the agreed test set.
- Benign prompt handling target: at least 90%.
- Planned test completion target: at least 95%.

These values are preliminary and must be confirmed with the project client.

# Key Decisions

The team agreed that:

1. The Week 2 requirements will remain the baseline requirements for Week 5.
2. The two main personas will be an AI Security Researcher and an AI Developer.
3. Five user stories will be used to connect stakeholder needs with project requirements.
4. FR1–FR4 remain relevant to the current project scope.
5. FR5 and FR6 will not be added unless a genuine stakeholder or implementation need is identified.
6. Jailbreak Detection Rate will retain the ≥80% target established in Week 2.
7. Benign Prompt Acceptance will retain the ≥90% target.
8. System Reliability will retain the ≥95% target.
9. Attack Success Rate (ASR) will be used as an evaluation metric where applicable.
10. GitHub will be used to maintain evidence of individual contributions.
